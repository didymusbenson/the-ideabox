# Crimson Heart — Assets

Visual references, model sheets, and other binary art for the webtoon.

## Layout
```
assets/
├── README.md                     # this file
└── character-designs/            # per-character model / reference sheets
    ├── crimson-heart-bunny-shinzo.md   # written design notes (canon-relevant)
    └── (drop image files here — see filenames below)
```

## Image files to add
The written notes live in `character-designs/*.md`. The **image binaries** should be
committed alongside them with these names (kept in sync with the notes):

- `character-designs/crimson-heart_teen-costume_ref.png` — original teenage costume sheet.
- `character-designs/crimson-heart_adult-costume_ref.png` — new adult-redesign costume sheet.

> These two reference sheets were provided by the author; add the PNGs at the paths above.
> (They couldn't be written straight from the chat session — drop them in or point the way
> and they'll be moved into place.)

## Convention
- One subfolder per asset type; per-character notes as markdown next to the art.
- Name files `<character>_<subject>_<kind>.<ext>` (e.g. `crimson-heart_adult-costume_ref.png`).
- Treat art as **reference**, not licensing; canon detail is mirrored into the character
  sheets under `loom/_books/crimson-heart/CHARACTERS/`.
