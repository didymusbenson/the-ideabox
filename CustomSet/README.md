# CustomSet — Unbelievable

A custom Magic: The Gathering set-design project for **Unbelievable**, developed as a complete, draftable expansion with original worldbuilding, mechanics, limited archetypes, a set skeleton, card file, and bonus sheet.

Start with [`SEED.md`](./SEED.md) for the project scope and working instructions. The `reference/` directory is the design knowledge base; active set development lives in `unbelievable/`.

## Contents

- [`SEED.md`](./SEED.md) — project goals, structure, and workflow
- [`reference/`](./reference/) — set-design reference library
- [`unbelievable/`](./unbelievable/) — active set files
- [`otherDesigns/`](./otherDesigns/) — adjacent custom-card explorations
- [`notes.md`](./notes.md) — feedback and open questions
